Overview

What is HANALYST SmartFix?

A solution developed by Inetum in pure ABAP that automatically analyses, suggests and applies the remediations required to make ECC code compatible with SAP S/4HANA — directly inside the SAP system, with full control and traceability.

🔍

Intelligent Scanner

Analyses packages, programs, classes and function groups. Integrates with ATC (ABAP Test Cockpit) for automatic findings.

🧠

Multi-LLM with Judge

Multiple AI models (Claude, Mistral, GPT and others) generate proposals in parallel. A "judge" layer automatically selects the best answer.

⚡

Deterministic Rules

For predictable transformations, applies exact rules without AI — faster, cheaper, guaranteed results.

✅

Individual Approval

Side-by-side comparison screen inside S/4HANA. Each change can be individually approved or rejected before being applied.

Process

How It Works

6 simple steps from scan to production deployment

1

Select

Choose the package or ABAP objects to analyse (PROG, CLAS, FUGR, INTF)

2

Scan

SmartFix scans the code and identifies legacy patterns — with or without ATC

3

Remediate

Multiple LLMs generate proposals via SAP AI Core in parallel. The judge picks the best.

4

Review

Side-by-side screen inside S/4HANA — approve or reject each change individually

5

Apply

One click applies all approved changes with a complete audit trail

6

Deploy
