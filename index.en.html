Overview

What is HANALYST SmartFix?

A pure ABAP solution developed by the SAP Technology team at Inetum Portugal that automatically analyses, suggests and applies the remediations required to make ECC code compatible with SAP S/4HANA — directly inside the SAP system.

🔍

Intelligent Scanner

Analyses packages, programs, classes and function groups. Integrates with ATC (ABAP Test Cockpit) for automatic findings.

🤖

AI Engine

Uses a generative LLM with rule-specific prompts to suggest the most context-appropriate remediation code.

⚡

Deterministic Rules

For predictable transformations, applies exact rules without AI — faster, cheaper, guaranteed results.

✅

Full Control

Review every change before applying. Automatic rollback, complete history and Transport Order integration.

Process

How It Works

6 simple steps from scan to production deployment

1

Select

Choose the package or ABAP objects to analyse (PROG, CLAS, FUGR, INTF)

2

Scan

SmartFix scans the code and identifies legacy patterns — with or without ATC

3

Remediate

Generative AI or deterministic rules generate the corrected code for each finding

4

Review

Visualise the full diff (before/after) and approve or reject each individual change

5

Apply

One click applies all approved changes with a complete audit trail

6

Deploy

Create transport requests and bring S/4HANA-ready code to production
